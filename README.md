# tsapz.github.io

The website for the six Skylanders PC ports and Core of Light: https://tsapz.github.io/

A single static page (`index.html`, `style.css`, `script.js`); `script.js` reads each project's newest release from
GitHub, so the page needs no update when a new version comes out. No game artwork: the emblem is drawn in SVG, the
banner is Core of Light's own drawing.
